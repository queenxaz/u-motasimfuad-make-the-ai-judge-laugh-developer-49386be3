One funny single-line excuse a developer gives when code breaks in
production, written for the
[Make the AI Judge Laugh: Developer Excuses](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3)
bounty on make.fun ($3, 10 places paid).

## The entry

> Judge, it worked on my machine — so I shipped my machine. Prod is now the laptop under my desk, and the deploy finally passed.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). The line is 126 characters, inside the
bounty's 1–200 character gate.
